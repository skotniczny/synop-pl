# 🌦️ Wizualizacja danych meteorologicznych z API IMGW

https://skotniczny.github.io/synop-pl/

Aplikacja wyświetla aktualne dane pomiarowe z IMGW na interaktywnej mapie oraz w tabeli z wyszukiwaniem i sortowaniem.

Umożliwia przełączanie pomiędzy danymi ze stacji synoptycznych i meteorologicznych:

## Synop – [danepubliczne.imgw.pl/api/data/synop](https://danepubliczne.imgw.pl/api/data/synop/)  

| Pomiar | Jednostka |
| --- | --- |
| Temperatura | °C |
| Prędkość wiatru | m/s |
| Kierunek wiatru | ° |
| Wilgotnosc względna | % |
| Suma opadu | mm |
| Ciśnienie | hPa |

## Meteo – [danepubliczne.imgw.pl/api/data/meteo](https://danepubliczne.imgw.pl/api/data/meteo/)  

| Pomiar | Jednostka |
| --- | --- |
| Temperatura powietrza | °C |
| Temperatura gruntu | °C |
| Kierunek wiatru | ° |
| Średnia prędkość wiatru | m/s |
| Maksymalna prędkość wiatru | m/s |
| Poryw wiatru (10 min) | m/s |
| Wilgotność względna | % |
| Opad (10 min) | mm |

---

Źródłem pochodzenia danych jest Instytut Meteorologii i Gospodarki Wodnej – Państwowy Instytut Badawczy
